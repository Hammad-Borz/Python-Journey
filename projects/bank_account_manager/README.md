# 🏦 Bank Account Manager

A beginner-level object-oriented Python project that models a simple bank account with deposit and withdrawal operations.

## 🐍 Requirements

- Python 3.10 or newer
- No external packages required

## ✨ Features

- Create an account with an initial balance
- Deposit money
- Withdraw money when sufficient funds are available
- Display the updated balance
- Prevent withdrawals that exceed the available balance

## 🛠️ Technologies

- Python
- Object-Oriented Programming (OOP)

## 📁 Project Structure

```text
bank_account_manager/
├── bank_account_manager.py
├── requirements.txt
└── README.md
```

## ⚙️ Installation

```bash
python -m venv .venv
```

No third-party dependencies need to be installed.

## 🚀 How to Run

```bash
python bank_account_manager.py
```

The current script runs example deposit and withdrawal operations automatically.
