# 📝 Smart Note Tool

A menu-driven Python application for storing, viewing, searching, and deleting notes from a text file.

## 🐍 Requirements

- Python 3.10 or newer
- No external packages required

## ✨ Features

- Add new notes
- View all saved notes
- Search notes using a word or phrase
- Delete a note by entering its exact text
- Exit through an interactive menu

## 🛠️ Technologies

- Python
- File handling
- Loops
- Conditional logic
- String processing

## 📁 Project Structure

```text
smart_note_tool/
├── smart_note_tool.py
├── note.txt
├── requirements.txt
└── README.md
```

## ⚙️ Installation

```bash
python -m venv .venv
```

No third-party dependencies need to be installed.

## 🚀 How to Run

```bash
python smart_note_tool.py
```

Choose an option from the interactive menu and follow the prompts.
